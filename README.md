# Franz & Lola · Levelwerkstatt

Statischer No-Code-Level-Editor für das gemeinsame `franz-lola-level`-JSON-Format. Er verwendet exakt dasselbe Renderer-Paket wie das Spiel und kann auf GitHub Pages betrieben werden.

## Funktionen

- Wände malen und radieren
- Startpunkt von Franz & Lola, Katzen und Schnüffel-Power setzen
- Passauer Themes und Farben auswählen
- Level automatisch auf Erreichbarkeit prüfen
- Undo/Redo sowie lokaler Entwurf in `localStorage`
- validiertes JSON importieren und exportieren

Später können zusätzliche Figuren-Renderer im gemeinsamen Format über das Feld `actors.*.renderer` ergänzt werden, ohne das Format zu brechen.
